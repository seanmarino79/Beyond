Above & Beyond Pediatric Therapy Note Generator — Version 4.3

HOW TO START
1. Unzip the folder.
2. Double-click "Start Therapy Note Generator.bat" on Windows, or open index.html in a modern browser.
3. For GitHub Pages, upload index.html to the root of the existing repository. The app is self-contained in that one file.

VERSION 4.3 CHANGES
- Added a context box for every selected temperament/emotion so the clinician can document what elicited it.
- Added "Sad" to the temperament choices so mixed emotions such as Happy + Sad can be documented clearly.
- When Block Stacking and Design is selected, a "How many blocks did they stack?" field appears.
- When Puzzles is selected, a "How many pieces were in the puzzle?" field appears.
- Those motor quantities are automatically incorporated into the generated narrative.
- Final narrative text is now 14-point in the print preview, generated PDF, and Word-compatible RTF.
- Existing Version 4 browser data is migrated when the new version is opened from the same website/browser origin.

DATA STORAGE
Clinical data is stored locally in the browser on the device. Use Export Backup regularly. GitHub Pages hosts the program code; this application does not send its locally saved session data to GitHub.
