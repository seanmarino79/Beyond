Above & Beyond Pediatric Therapy Note Generator — Version 4.4

HOW TO START
1. Unzip the folder.
2. Double-click "Start Therapy Note Generator.bat" on Windows, or open index.html in a modern browser.
3. For GitHub Pages, upload index.html to the root of the existing repository. The app is self-contained in that one file.

VERSION 4.4 CHANGES
- Added Object Permanence and Shape Sorter under Receptive Communication & Cognitive Skills.
- Added Stringing Beads under Motor Activities.
- Added the complete Caregiver Coaching / EI Strategies section from the EI OT concept: Caregiver Education, Collaborative Problem Solving, Environmental Adaptation, Guided Caregiver Practice, Home Strategy Development, Modeling / Demonstration, Positioning Education, Routine Modification, Sensory Education, and Visual / Written Support.
- Added Caregiver Response options and incorporated caregiver coaching/response into the generated narrative.
- Existing Version 4.3 browser data is migrated when opened from the same site/browser origin.

DATA STORAGE
Clinical data is stored locally in the browser on the device. Use Export Backup regularly. GitHub Pages hosts the program code; this application does not send its locally saved session data to GitHub.
